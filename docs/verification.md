# Проверка

## Автоматические проверки

Из корня проекта выполните:

```bash
python3 -m unittest discover -s tests -v
python3 -m py_compile spectra_app.py gaussian_parser.py experimental_parser.py spectrum_processing.py project_io.py
QT_QPA_PLATFORM=offscreen python3 spectra_app.py --smoke-test
```

Первый запуск проверяет извлечение полного блока мод и отказ при незавершённом или ошибочном Gaussian-задании. Последние две команды проверяют синтаксис и создание окна без графического дисплея.

Интеграционная проверка открывает `tests/fixtures/water.log` и `tests/fixtures/experimental.csv`, применяет baseline-коррекцию, экспортирует PNG и убеждается, что JSON-проект можно восстановить в новом окне.

## Контрольный файл

Для предоставленного `water.log` ожидаются следующие результаты:

| Свойство | Ожидаемое значение |
| --- | --- |
| Финальный статус | `Normal termination of Gaussian` |
| Число мод | 48 |
| Минимальная частота | 29.3182 см⁻¹ |
| Максимальная частота | 3802.9208 см⁻¹ |
| Максимальная ИК-интенсивность | 2465.7445 KM/mol |
| Максимальная Raman activity | 287.8862 Å⁴/amu |

## Ручная проверка

1. Запустите приложение.
2. Выберите **Файл → Открыть Gaussian log**.
3. Укажите `water.log`.
4. Убедитесь, что таблица содержит 48 строк, а статус показывает имя файла и число мод.
5. Переключите Raman/ИК: кривая должна перестроиться, а значения в таблице остаться неизменными.
6. Измените контур, ширину пика, масштаб частот и направление X: отображение должно обновляться без повторного импорта.
7. Импортируйте двухколоночный `.csv`, `.txt` или `.xy`: в графике должны появиться исходная кривая, baseline и скорректированный результат.
