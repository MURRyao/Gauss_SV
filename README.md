# Gaussian Spectra

Desktop-приложение для построения и визуального сопоставления теоретических ИК/Raman-спектров из Gaussian с экспериментальными двухколоночными спектрами.

## Возможности

- Импорт завершённых Gaussian `.log` и `.out`: частоты, ИК-интенсивности, Raman activity, `Depolar (P)` и `Depolar (U)`.
- Построение ИК- и Raman-спектров с Gaussian, Lorentzian или приближённым Voigt-контуром.
- Масштаб частот, нормализация, рабочий диапазон, обратная ось X, настройки лазера, температуры и поляризации Raman.
- Импорт экспериментальных `.csv`, `.txt` и `.xy` с двумя числовыми колонками.
- Baseline-коррекция ALS, airPLS, линейным или квадратичным полиномом.
- Экспорт текущего графика в PNG или JPEG.
- Самодостаточные JSON-проекты: сохраняют импортированные точки, моды и параметры отображения, поэтому исходные файлы для повторного открытия не нужны.

## Требования

- Python 3.10 или новее.
- Библиотеки из `requirements.txt` (`PySide6`, NumPy, SciPy).

## Установка и запуск

В корне репозитория выполните:

```bash
python3 -m pip install -r requirements.txt
python3 spectra_app.py
```

Для Linux без графической сессии можно убедиться, что окно создаётся:

```bash
QT_QPA_PLATFORM=offscreen python3 spectra_app.py --smoke-test
```

## Быстрый сценарий работы

1. Нажмите **Открыть Gaussian log** и выберите завершённый расчёт `.log` или `.out`. Файл принимается, если последнее сообщение задания — `Normal termination of Gaussian`.
2. В блоке **Построение спектра** выберите ИК или Raman, контур, ширину, масштаб частот и нормализацию. Для Raman доступны параметры лазера, температуры и поляризации.
3. При необходимости нажмите **Импортировать XY** и выберите файл с волновым числом и интенсивностью. Разрешены запятая, точка с запятой, табуляция и пробелы; заголовки игнорируются.
4. В блоке **Baseline-коррекция** выберите метод и нажмите **Применить baseline**. На графике будут видны исходная кривая, baseline и скорректированный сигнал.
5. Выделяйте строки таблицы или щёлкайте рядом с расчётным пиком: выбранная мода помечается на графике.
6. Нажмите **Экспорт графика**, чтобы сохранить текущее представление в PNG/JPEG. Используйте **Сохранить проект**, чтобы записать данные и настройки в JSON; файл открывается через **Файл → Открыть проект**.

## Меню

- **Файл** — импорт Gaussian и экспериментального спектра, открытие/сохранение проекта.
- **Спектр** — экспорт графика, сброс параметров спектра, удаление экспериментальной кривой.
- **Вид** — сброс выделенной моды.
- **Справка** — краткая последовательность работы и сведения о приложении.

## Проверка

Запуск полного набора проверок:

```bash
python3 -m unittest discover -s tests -v
python3 -m py_compile spectra_app.py gaussian_parser.py experimental_parser.py spectrum_processing.py project_io.py
QT_QPA_PLATFORM=offscreen python3 spectra_app.py --smoke-test
```

Интеграционный тест использует файлы `tests/fixtures/water.log` и `tests/fixtures/experimental.csv`: импортирует оба спектра, строит baseline, экспортирует PNG, сохраняет проект и восстанавливает его в новом окне.

## Ограничения

Приложение не открывает бинарные Gaussian `.chk`. Raman-представление предназначено для сравнительного анализа и не является расчётом абсолютного сечения рассеяния. Наложение теоретического и экспериментального спектров визуальное: автоматическая подгонка пиков и абсолютная калибровка интенсивностей пока не реализованы.

Подробности реализации находятся в [docs/README.md](docs/README.md).

Подробный сценарий работы приведён в [руководстве пользователя](docs/user-guide.md).
