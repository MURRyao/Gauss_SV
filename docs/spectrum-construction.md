# Построение и обработка спектров

## Теоретический спектр

Расчёт Gaussian задаёт набор дискретных мод. Приложение строит непрерывную кривую на равномерной сетке волновых чисел, суммируя профиль каждой моды.

| Параметр | Действие |
| --- | --- |
| Тип спектра | Использует ИК-интенсивность или Raman activity. |
| Контур | Gaussian, Lorentzian либо приближённый Voigt (поровну Gaussian/Lorentzian). |
| Ширина пика | Полная ширина на полувысоте в см⁻¹. |
| Масштаб частот | Умножает каждую гармоническую частоту перед построением. |
| Нормализация | Без преобразования, максимум = 1 либо максимум = 100. |
| Направление X | Меняет только отображение оси; данные не переставляются. |

## Raman

Для Raman применяется относительный Stokes-вес: Raman activity умножается на четвёртую степень сдвинутой частоты лазера и температурный множитель. Параллельный и перпендикулярный режимы распределяют активность по коэффициенту `Depolar (P)`, извлечённому из Gaussian. Это сравнительная визуализация, а не абсолютное сечение рассеяния.

Если `Depolar (P)` отсутствует, для относительного отображения принимается значение 0.75.

## Экспериментальные данные

Импортируются текстовые двухколоночные спектры `.csv`, `.txt` и `.xy`. Поддержаны пробелы, табуляция, запятая и точка с запятой в роли разделителей; для точек с запятой разрешена десятичная запятая. Заголовки и строки, начинающиеся с `#`, `//` или `;`, игнорируются.

После импорта на графике показаны исходная кривая, оценённая baseline и baseline-скорректированная кривая.

## Baseline-коррекция

| Метод | Назначение |
| --- | --- |
| ALS | Asymmetric least squares; базовый вариант для плавного фона. |
| airPLS | Адаптивная итеративная взвешенная аппроксимация; устойчива к выраженным пикам. |
| Линейный | Линия через первую и последнюю точки. |
| Полином 2-й степени | Глобальный квадратичный фон. |

Для ALS и airPLS `λ = 10^n` задаёт степень сглаживания. В ALS параметр асимметрии определяет, насколько пики исключаются из оценки baseline.
