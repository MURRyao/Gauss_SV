# Импорт Gaussian log

## Поддерживаемые файлы

Поддерживаются текстовые файлы Gaussian с расширениями `.log` и `.out`, содержащие расчёт частот с Raman-активностями, например маршрут с `freq=raman`.

## Условие принятия

Импорт выполняется только если последнее сообщение о завершении задания имеет вид `Normal termination of Gaussian`. Если последнее завершение — `Error termination`, файл отклоняется: результаты такого задания могут быть неполными.

## Извлекаемые данные

Gaussian группирует до трёх мод в блоке. Для каждой группы парсер сопоставляет строки:

```text
Frequencies --
IR Inten    --
Raman Activ --
```

Число значений в трёх строках обязано совпадать. Каждая распознанная мода получает последовательный номер, частоту, ИК-интенсивность и Raman activity.

## Ошибки импорта

| Ситуация | Результат |
| --- | --- |
| Нет `Normal termination` | Импорт отклонён. |
| Последняя запись — `Error termination` | Импорт отклонён. |
| Неполный блок частот | Импорт отклонён. |
| Число частот и интенсивностей различается | Импорт отклонён. |
| Частотные блоки отсутствуют | Импорт отклонён. |

## Ограничения

Парсер не открывает `.chk`: это бинарный служебный формат Gaussian. Для импорта спектра используйте `.log` или `.out`.
