# Руководство пользователя

## 1. Загрузка расчёта Gaussian

Выберите **Файл → Открыть Gaussian log** или кнопку **Открыть Gaussian log**. Поддерживаются текстовые `.log` и `.out` с расчётом частот. Файл принимается только при финальном сообщении `Normal termination of Gaussian`.

После загрузки таблица содержит частоту, ИК-интенсивность, Raman activity и коэффициенты деполяризации каждой нормальной моды. Щелчок по строке или пику связывает выделение в таблице и графике.

## 2. Настройка расчётного спектра

В панели **Построение спектра** выберите ИК или Raman, форму линии и её ширину. Масштаб частот полезен для применения эмпирического поправочного коэффициента к гармоническим частотам. Диапазон управляет рабочей областью графика; включение обратной оси отображает большие волновые числа слева.

Для Raman доступны длина волны лазера, температура и поляризация. Эти настройки влияют на относительные интенсивности, но не меняют исходные данные Gaussian в таблице.

## 3. Экспериментальный спектр и baseline

Нажмите **Импортировать XY** и выберите двухколоночный `.csv`, `.txt` или `.xy` файл. После импорта активируется блок **Baseline-коррекция**.

1. Выберите ALS, airPLS, линейный или полиномиальный метод.
2. Для ALS/airPLS задайте степень сглаживания `λ = 10^n`; при необходимости измените асимметрию и число итераций.
3. Нажмите **Применить baseline**.

График показывает исходный экспериментальный сигнал серым, baseline пунктиром и результат вычитания бордовым цветом. Расчётный спектр показан синим.

## Ограничения

Raman-представление предназначено для сравнительного анализа и не является расчётом абсолютного сечения рассеяния. Baseline-коррекция изменяет только импортированный экспериментальный сигнал; расчётный спектр Gaussian остаётся с нулевой baseline.
